## Підключення

### Мікроконтролер (STM32F411 Black Pill)

| Пін | Периферія | Підключення |
|---|---|---|
| PA0 | ADC1_IN0 | Потенціометр 2.2 кОм, середній вивід |
| PA8 | TIM1_CH1, PWM 1 кГц | Резистор 180 Ом → світлодіод PC817 №1 → DRV8833 IN1 |
| PA9 | TIM1_CH2, PWM 1 кГц | Резистор 180 Ом → світлодіод PC817 №2 → DRV8833 IN2 |
| PB6 | TIM4_CH1, режим енкодера, внутрішня підтяжка | KY-040 CLK |
| PB7 | TIM4_CH2, режим енкодера, внутрішня підтяжка | KY-040 DT |
| PC13 | GPIO | Світлодіод на платі |
| PA11, PA12 | USB FS | Консоль (USB CDC) |

### Оптрони PC817 (817B), 2 шт.

| Вивід | Підключення |
|---|---|
| 1 (анод) | PA8 / PA9 через резистор 180 Ом |
| 2 (катод) | GND_MCU |
| 3 (емітер) | GND_POWER |
| 4 (колектор) | DRV8833 IN1 / IN2, підтяжка 2.2 кОм до +5 В |

Оптрони інвертують сигнал: високий рівень на виході МК дає низький рівень
на вході драйвера. Обидва входи у високому рівні — гальмування.

### Драйвер DRV8833 (модуль)

| Вивід | Підключення |
|---|---|
| IN1 | Колектор PC817 №1 |
| IN2 | Колектор PC817 №2 |
| OUT1 | Двигун, червоний провід |
| OUT2 | Двигун, чорний провід |
| EEP (nSLEEP) | Запаяна перемичка на модулі, драйвер завжди увімкнений |
| Живлення | +5 В, GND_POWER |

### Енкодер KY-040

| Вивід | Підключення |
|---|---|
| CLK | PB6 |
| DT | PB7 |
| SW | Не використовується |
| + | +3,3 В |
| GND | GND_MCU |

### Потенціометр 10 кОм

Крайні виводи: +3,3 В і GND_MCU, середній вивід: PA0.

### Живлення

- Цифрова частина: +3,3 В, GND_MCU (МК, потенціометр, енкодер)
- Силова частина: +5 В, GND_POWER (DRV8833, двигун)
- Землі між собою не з'єднані

## PID

- Ku = ~150
- PID (без перерегулювання):
  - Kp = 30
  - Tu = 0.15
  - Ti = 0.075
  - Td = 0.05
  - Ki = Kp / Ti = 400
  - Kd = Kp * Td = 1.5
